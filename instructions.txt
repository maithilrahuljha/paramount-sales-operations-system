    • 🎓 Education      (text input — editable)

    • 📝 Notes          (textarea — editable)

  BEFORE: Modal showed read-only text. Staff could only change status.
  AFTER:  Modal has input fields. Staff can correct any detail.

HOW IT WORKS:

  1. Counsellor clicks ✏️ Edit on a lead
  2. Modal opens with all fields pre-filled with current values
  3. Counsellor changes whatever needs updating:
     • Fix a typo in the name
     • Update phone number
     • Reassign to different counsellor
     • Change course interest
     • Change batch month
  4. Counsellor clicks 💾 Save Changes
  5. Dashboard sends ALL field values to Apps Script:
     { action: 'updateLead',
       leadId: 'PMN-2026-0001',
       status: 'Contacted',
       notes: 'Updated phone number',
       fields: '{"name":"John Doe","phone":"9999999999","course":"GP Rating",...}' }
  6. Apps Script updates EVERY column in the main sheet
  7. Dashboard refreshes with updated values

  Save button enables when ANY field is changed (not just status/notes).

FILES INVOLVED:
  • dashboard_ui/index.html — input fields in modal
  • dashboard_ui/style.css — .edit-grid, .edit-input styles
  • dashboard_ui/app.js — enableSave() checks all fields for changes
  • apps_script_backup/Code.gs — updateLead() parses "fields" JSON
    and writes each value to the matching column

WHAT WILL BE BUILT:

  A complete enrollment workflow where counsellors fill a Google Form
  with fee details and upload documents. The system auto-creates a

  COUNSELLOR SEES:

  2. Alert: "✅ Enrolled! Fill enrollment form →" with clickable link
  3. Google Form opens PRE-FILLED with: Lead ID, Name, Phone, Email, Course
  4. Counsellor fills: Fee Amount, Due Date, Payment Mode

  2. Generates Enrollment_ID: ENR-2026-0001

  4. Moves uploaded documents into that folder
  5. Writes folder URL back to the sheet

  COUNSELLOR NEVER TOUCHES:
  ❌ Google Sheets directly
  ❌ Google Drive directly
  ❌ Student_Master_DB sheet
  Everything through Dashboard + Form.

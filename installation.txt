📖 PART 1: UNDERSTANDING WHAT WE'RE BUILDING
================================================================================

🤔 What is this system?

Think of it like a smart assistant that helps you:

   ✅ Capture new student leads through a form
   ✅ Automatically organize all leads in a spreadsheet
   ✅ Give each lead a unique ID (like PMN-2026-0001)
   ✅ Show you a beautiful dashboard with charts and numbers
   ✅ Send you a morning report every day at 8:30 AM
   ✅ Keep track of who needs follow-up calls
   ✅ Archive old leads automatically every month

🧩 The pieces we'll set up:

   📝 Google Forms    = Where new leads fill in their information
   📊 Google Sheets   = Where all the data is stored (like Excel)
   🤖 Apps Script     = A small program that creates Lead IDs automatically
   🌐 GitHub Pages    = Where your dashboard website will live
   ⚙️ GitHub Actions  = Robots that run tasks automatically (morning reports, etc.)
   📈 Looker Studio   = Advanced charts and reports (we'll do this last)

💰 Cost: COMPLETELY FREE! 

All these tools are free to use. You won't need to pay anything.

🔐 Is it safe?

Yes! Your data stays in YOUR Google account. You control who can see it.

📊 PART 3: SETTING UP GOOGLE SHEETS
================================================================================

We need to create a folder and some spreadsheets. Think of this like 
creating folders and files on your computer, but online.

───────────────────────────────────────────────────────────────────────────────
STEP 3.1: Create the Main Folder
───────────────────────────────────────────────────────────────────────────────

1. Make sure you're on Google Drive (https://drive.google.com)

2. Look for a button that says "+ New" (usually top-left corner with a + sign)

3. Click "+ New"

4. A menu will appear. Click "New folder"

5. A small box will pop up asking for the folder name

6. Type exactly: Paramount_CRM_Data

7. Click "Create"

8. You'll see your new folder appear in the list

9. DOUBLE-CLICK on the folder to open it (go inside it)

📍 You should now be INSIDE the Paramount_CRM_Data folder
   (You can tell by looking at the top - it should show the folder name)

───────────────────────────────────────────────────────────────────────────────
STEP 3.2: Create the Lead Register Spreadsheet
───────────────────────────────────────────────────────────────────────────────

1. Make sure you're INSIDE the Paramount_CRM_Data folder

2. Click "+ New" again

3. This time, click "Google Sheets"

4. A new spreadsheet will open in a new tab

5. Look at the top-left corner - you'll see "Untitled spreadsheet"
   Click on those words

6. Type exactly: Lead_Register

7. Press Enter (the name is now saved)

───────────────────────────────────────────────────────────────────────────────
STEP 3.3: Add Column Headers to Lead Register
───────────────────────────────────────────────────────────────────────────────

Now we need to add the column titles. These MUST be exact!

1. Click on cell A1 (the very first cell, top-left)

2. Type: Lead_ID

3. Press the TAB key on your keyboard (this moves to the next cell)

4. Type: Candidate Full Name

5. Press TAB

6. Continue typing these headers, pressing TAB after each one:

   Cell A1:  Lead_ID
   Cell B1:  Candidate Full Name
   Cell C1:  Email Address
   Cell D1:  Phone Number
   Cell E1:  City / Location
   Cell F1:  Course Interested In
   Cell G1:  How did you hear about us?
   Cell H1:  Preferred Batch Month
   Cell I1:  Current Education Level
   Cell J1:  Counsellor Assigned
   Cell K1:  Additional Remarks
   Cell L1:  Status

7. After typing "Status" in L1, press Enter

───────────────────────────────────────────────────────────────────────────────
STEP 3.4: Format the Header Row (Make it look nice)
───────────────────────────────────────────────────────────────────────────────

1. Click on the "1" on the left side (this selects the entire row 1)
   The whole row should turn blue/highlighted

2. Look for the paint bucket icon in the toolbar (Fill color)
   Click the small arrow next to it

3. Choose a dark blue color (like navy blue)

4. The row is now dark blue, but you can't see the text!

5. Look for the "A" with a colored bar under it (Text color)
   Click the small arrow next to it

6. Choose WHITE

7. Now look for the "B" button (Bold)
   Click it to make the text bold

8. Your header row should now look professional! 
   Dark blue background, white bold text.

───────────────────────────────────────────────────────────────────────────────
STEP 3.5: Freeze the Header Row
───────────────────────────────────────────────────────────────────────────────

"Freezing" means the header row will always stay visible when you scroll down.

1. Click on "View" in the menu bar (top of screen)

2. Click on "Freeze"

3. Click on "1 row"

✅ Done! Now when you have many leads, you'll always see the headers.

───────────────────────────────────────────────────────────────────────────────
STEP 3.6: Save the Spreadsheet ID (IMPORTANT!)
───────────────────────────────────────────────────────────────────────────────

We need to save the spreadsheet's unique ID for later.

1. Look at your browser's address bar (where the website URL is shown)

2. You'll see something like:
   https://docs.google.com/spreadsheets/d/1ABC123XYZ.../edit

3. The long string of letters and numbers after "/d/" is your Spreadsheet ID
   In this example, it would be: 1ABC123XYZ...

4. Open Notepad (Windows) or TextEdit (Mac) or any text app

5. Create a new file and write:

   ============================================
   MY PARAMOUNT CRM - IMPORTANT IDs
   (Keep this file safe!)
   ============================================
   
   Lead_Register Spreadsheet ID:
   [Paste your ID here]
   
   Lead_Register URL:
   [Paste the full URL here]

6. Save this file somewhere safe - you'll need these IDs later!

STEP 4.1: Open Google Forms
───────────────────────────────────────────────────────────────────────────────

1. Open a new browser tab

2. Go to: https://forms.google.com

4. Click the big "+" button or "Blank" to create a new form

───────────────────────────────────────────────────────────────────────────────

───────────────────────────────────────────────────────────────────────────────
STEP 4.3: Add Questions (Follow this EXACTLY)
───────────────────────────────────────────────────────────────────────────────

We'll add each question one by one. Take your time!

📌 QUESTION 1: Candidate Full Name

1. You'll see a question box that says "Untitled Question"

2. Click on "Untitled Question" and type: Candidate Full Name

3. On the right side, you'll see a dropdown (probably says "Multiple choice")
   Click it and select "Short answer"

4. At the bottom right of the question box, you'll see "Required"
   Click the toggle switch to turn it ON (it should turn purple/blue)

📌 QUESTION 2: Email Address

1. Look at the right side of the question box - there's a "+" icon
   OR hover over the question box and click the "+" that appears

2. Click "+" to add a new question

3. Type: Email Address

4. Set type to: Short answer

5. Toggle Required: ON

6. BONUS: Click the three dots (⋮) at the bottom of the question
   Click "Response validation"
   Set it to: "Text" → "Email" → "Must be email"
   (This makes sure people enter a real email format)

📌 QUESTION 3: Phone Number

1. Click "+" to add new question

2. Type: Phone Number

3. Set type to: Short answer

4. Toggle Required: ON

📌 QUESTION 4: City / Location

1. Click "+" to add new question

2. Type: City / Location

3. Set type to: Short answer

4. Toggle Required: ON

📌 QUESTION 5: Course Interested In

1. Click "+" to add new question

📌 QUESTION 6: How did you hear about us?

2. Type: How did you hear about us?

3. Set type to: Dropdown

4. Add these options:
   • Facebook
   • Instagram
   • Google Search
   • YouTube
   • Friend/Family Referral
   • Walk-in
   • Website
   • Education Fair
   • Other

5. Toggle Required: ON

📌 QUESTION 7: Preferred Batch Month

1. Click "+" to add new question

2. Type: Preferred Batch Month

3. Set type to: Dropdown

4. Add these options:
   • January
   • February
   • March
   • April
   • May
   • June
   • July

☁️ PART 7: GOOGLE CLOUD SETUP (SERVICE ACCOUNT)
================================================================================

This is the most technical part, but don't worry - just follow each step!

A "Service Account" is like a robot assistant with its own email address 
that can access your spreadsheets automatically.

───────────────────────────────────────────────────────────────────────────────
STEP 7.1: Open Google Cloud Console
───────────────────────────────────────────────────────────────────────────────

1. Open a new browser tab

2. Go to: https://console.cloud.google.com

3. You'll be asked to sign in with your Google account
   Use the same account that has your spreadsheets

4. You might see a welcome message or terms of service
   Click "Agree and Continue"

───────────────────────────────────────────────────────────────────────────────
STEP 7.2: Create a New Project
───────────────────────────────────────────────────────────────────────────────

1. Look at the top of the page
   You'll see "Select a project" with a dropdown arrow

2. Click on it

3. A popup appears. Click "NEW PROJECT" (top right of popup)

4. Enter these details:
   • Project name: Paramount-CRM
   • Organization: Select "No organization" 
     (IMPORTANT: If you see organization options, choose "No organization")
   • Location: Leave as default

5. Click "CREATE"

6. Wait 30-60 seconds for the project to be created
   You'll see a notification when it's done

7. Click "SELECT PROJECT" in the notification
   OR click the project dropdown and select "Paramount-CRM"

───────────────────────────────────────────────────────────────────────────────
STEP 7.3: Enable Google Sheets API
───────────────────────────────────────────────────────────────────────────────

"APIs" are like special doorways that let programs talk to Google services.

1. In the left menu, click "APIs & Services"
   (If you don't see a menu, click the ☰ hamburger icon at top left)

2. Click "Library"

3. In the search box, type: Google Sheets API

4. Click on "Google Sheets API" in the results

5. Click the blue "ENABLE" button

6. Wait a few seconds for it to enable

───────────────────────────────────────────────────────────────────────────────
STEP 7.4: Enable Google Drive API
───────────────────────────────────────────────────────────────────────────────

1. Click "Library" again (left menu → APIs & Services → Library)

2. Search for: Google Drive API

3. Click on "Google Drive API"

4. Click "ENABLE"

───────────────────────────────────────────────────────────────────────────────
STEP 7.5: Create Service Account
───────────────────────────────────────────────────────────────────────────────

1. In the left menu, click "APIs & Services"

2. Click "Credentials"

3. At the top, click "+ CREATE CREDENTIALS"

4. Select "Service account"

5. Fill in:
   • Service account name: paramount-crm-sa
   • Service account ID: (this fills automatically)
   • Description: Service account for CRM automation

6. Click "CREATE AND CONTINUE"

7. In "Grant this service account access to project":
   • Click the dropdown "Select a role"
   • Search for "Editor"
   • Select "Editor"

8. Click "CONTINUE"

9. Skip the third step (grant users access)
   Just click "DONE"

───────────────────────────────────────────────────────────────────────────────
STEP 7.6: Create and Download the Secret Key (JSON)
───────────────────────────────────────────────────────────────────────────────

This creates a special file that acts like a password for the robot assistant.

1. You should see your service account in the list
   It has an email like: paramount-crm-sa@paramount-crm.iam.gserviceaccount.com

2. COPY this email address and save it to your Notepad:

    Service Account Email:
    [Paste the email here]

3. Click on the service account email (it's a clickable link)

4. Click the "KEYS" tab at the top

5. Click "ADD KEY"

6. Click "Create new key"

7. Select "JSON"

8. Click "CREATE"

9. A file will automatically download to your computer!
   It's called something like "paramount-crm-xxxxx.json"

10. Find this file in your Downloads folder
    KEEP IT SAFE - don't share it with anyone!

───────────────────────────────────────────────────────────────────────────────
STEP 7.7: Share Your Folder with the Service Account
───────────────────────────────────────────────────────────────────────────────

Now we need to give the robot assistant permission to access your files.

1. Go to Google Drive (https://drive.google.com)

2. Find your "Paramount_CRM_Data" folder

3. Right-click on the folder

4. Click "Share"

5. In the "Add people" field, paste the Service Account Email
   (the one that ends with @....iam.gserviceaccount.com)

6. Change the permission from "Viewer" to "Editor"
   (Click the dropdown next to the email)

7. UNCHECK "Notify people" (the robot doesn't need emails!)

8. Click "Share"

================================================================================
❓ TROUBLESHOOTING
================================================================================

Problem: Dashboard shows "--" instead of numbers
Solution: Your CSV URL might be wrong or expired. Re-publish the sheet:
         File → Share → Publish to web → Republish

Problem: Lead ID not generating
Solution: Check Apps Script trigger:
         Open Sheet → Extensions → Apps Script → Triggers → Make sure one exists

Problem: Morning briefing not received
Solution: Check GitHub Actions:
         Go to GitHub → Actions → Check if workflows are running
         Check Secrets → Make sure all 5 secrets are added

Problem: "Permission Denied" errors
Solution: Make sure you shared the Drive folder with the service account email

Problem: Form responses not appearing in sheet
Solution: Check form linking:
         Open Form → Responses → Click spreadsheet icon → Re-link to sheet

Problem: Dashboard not loading at all
Solution: 
         1. Check GitHub Pages is enabled (Settings → Pages)
         2. Check config.js has correct URLs
         3. Clear browser cache (Ctrl+F5)
